# Opeyemi Gbadamosi — Quality Engineering Portfolio

A personal portfolio showcasing Opeyemi Gbadamosi’s work as a QA engineering leader and senior automation engineer. It brings together quality strategy, team leadership and hands-on engineering across web, mobile and API testing, with cybersecurity as a complementary discipline.

[View the portfolio](https://gb-opeyemi.github.io/)

## Features

- Responsive dark and light themes with purple accents and layouts for desktop and mobile.
- Accessible theme switch that remembers the visitor’s choice and otherwise follows their system preference.
- Professional introduction, career timeline and selected engineering initiatives.
- Categorised technical skills, certifications, education and community experience.
- Downloadable CV and links to email, LinkedIn and GitHub.
- Expandable project details, subtle animations and email-copy interaction.
- Semantic HTML, a skip link, visible keyboard focus and reduced-motion support.
- Search and social metadata, plus structured profile data.

## Built with

The site uses HTML, CSS and vanilla JavaScript. It requires no frontend framework, package installation, build step or backend. Google Fonts provides the typography, with system fonts as fallbacks.

The page content and download links remain available without JavaScript. JavaScript enhances navigation, project animations and email copying.

## Project structure

```text
.github/workflows/pages.yml    GitHub Pages deployment workflow
dist/
  index.html                  Page content and metadata
  styles.css                  Design, layout and responsive styles
  app.js                      Interactive enhancements
  assets/                     Portrait, CV and favicon
scripts/
  check_site.py               Static markup and local-reference checks
package.json                  Development and validation commands
```

`dist/` contains the complete deployable website; it is maintained directly rather than generated by a build tool.

## Run locally

Install Node.js and Python 3, then clone the repository:

```bash
git clone https://github.com/Gb-opeyemi/gb-opeyemi.github.io.git
cd gb-opeyemi.github.io
npm run dev
```

Open [http://127.0.0.1:4173](http://127.0.0.1:4173). No `npm install` step is needed.

To serve the site without Node.js:

```bash
python3 -m http.server 4173 --directory dist --bind 127.0.0.1
```

## Validation

```bash
npm run check
```

This checks JavaScript syntax, local file references, internal anchor targets, image alternative text and the presence of a single primary heading. These checks complement manual browser and accessibility review.

## Deployment

The included GitHub Actions workflow validates the site and deploys `dist/` to GitHub Pages on pushes to `main`. It can also be run manually from the Actions tab.

For a fork or another repository, enable **GitHub Actions** as the publishing source under **Settings → Pages**. The workflow expects the project files at the repository root.

The contents of `dist/` can also be hosted by any static web host. Relative asset paths support both root domains and repository subpaths.

## Adapting the site

The source provides a straightforward reference for a static professional portfolio:

- Edit `dist/index.html` to change the profile, experience, projects, skills and contact links.
- Adjust `dist/styles.css` to customise colours, spacing, typography and breakpoints.
- Update `dist/app.js` when changing interactive behaviour, including the email address used by the copy button.
- Replace the portrait, CV and favicon in `dist/assets/`, and update references if filenames change.
- Update the page title, description, social metadata and structured profile data for the new site and owner.
- Review `.gitignore`: image and document formats are ignored by default, with explicit exceptions for the portfolio’s published photo and CV. Add exceptions for any replacement assets intended for deployment.
